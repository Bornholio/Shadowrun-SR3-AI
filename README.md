This Repo is for a personal Shadowrun 3rd Edition Campaign.
Campaign is run via Claude AI.

**Current Status:** Session 14 complete — Session 15 pending.

---

## How Sessions Work

Three root files are loaded at the start of every session, in order:

1. `1_chat_control.md` — session management, skill load triggers, dice protocol, modes
2. `2_sr3_game_rules.md` — SR3 edition lock, rolling conventions, stat format, campaign rules
3. `3_session_header.md` — current situation, active assets, intel picture, open threads, GM-only mystery architecture

After the three root files, load active character sheets and any supplemental files the session requires.
