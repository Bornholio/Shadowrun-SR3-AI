# SR3 SPELLCASTING — GM REFERENCE

**Edition Lock: SR3 only.**

---

## GM STYLE

- Infer as much as possible from context (spell name, force, target described)
- If info is missing, ask for it all in one compact message before rolling
- During resolution: state result + prompt next roll only — no rule narration
- Sequence: Sorcery Test → Target Resists → Resolve Effect → Drain

---

## WHAT TO INFER / WHAT TO ASK

**Infer from spell name:** mana vs physical, damage type, base damage level
**Infer from context:** target type (living/object), likely attributes

**Ask if missing (one message):**
- Caster: Sorcery dice, Spell Pool available, Magic rating, Willpower, sustained spells
- Target: relevant resistance attribute (Willpower for mana, Body for physical)

---

## SORCERY TEST

Roll: **Sorcery + Spell Pool** (Pool ≤ Sorcery dice)
TN: **Willpower** (mana) | **Body** (physical) | **Object Resistance** (inanimate)

Modifiers: +2 TN per sustained spell | +Force of any astral barrier crossed

0 successes = spell fails. All ones = fail + Drain TN +2.

---

## SPELL EFFECT

Net successes = caster − target. 

---

## DRAIN RESISTANCE

Roll: **Willpower + Spell Pool** (drain-allocated) vs **TN = Force ÷ 2 (round down)**
Every 2 successes = −1 Drain level. Below Light = no damage.

Drain type: **Stun** if Force ≤ Magic. **Physical** if Force > Magic. Astral projection = always Physical.

---

## LIMITED SPELLS

| Limit | Drain Modifier | Effect |
|---|---|---|
| Fetish | −1 Force | Requires attuned fetish physically touching caster; if lost, Force hours meditation to re-attune |
| Exclusive | −2 Force | Both casting and sustaining are Exclusive Actions |

Modifier reduces Drain Force **or** Karma cost at learning — choose one. A spell may carry both limits; each applies separately. The unrestricted version must be learned as a separate spell.

---

## OBJECT RESISTANCE

| Category | TN |
|---|---|
| Natural | 3 |
| Low-tech manufactured | 5 |
| High-tech manufactured | 8 |
| Highly processed | 10+ |
