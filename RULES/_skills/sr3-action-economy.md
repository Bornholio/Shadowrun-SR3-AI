# SR3 Action Economy
*Skill file — load on demand*
*Source: SR3, Rigger 3, Matrix, MitS, Critters*

---

## Turn

**Duration: 3 seconds.**
All dice pools refresh at start of each Turn. Unused dice lost at end of turn. Karma Pool refreshes every 24 hours.
If time critical; roll initiative for characters; (Init/10)↑ Phases per turn


## Actions Per Phase

| Option | Allocation |
|---|---|
| Standard | 2 Simple Actions |
| Alternative | 1 Complex Action |
| Always available | +1 Free Action (any one Phase) ¹ |

*¹ Multi-Tasking adept power: 2 Free Actions per Phase instead of 1.*

**Free Action timing:** Declared at start of Phase. May be used in another character's Phase (resolves last) — only after character's first Phase in the turn.
