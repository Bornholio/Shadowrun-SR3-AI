# SR3 Roll Display Rules

- Use an actual random d6 method for every GM-controlled roll.
- Resolve the entire roll before displaying it.
- Show each die only as its **final SR3 value**.
- When the Rule of Six applies(ALWAYS), explode each 6 until complete and show only the accumulated result: `8`, `13`, `20`, etc.
- Do not show intermediate notation such as `6+2` or `6→2` unless the GM asks for it.
- If a TN above 6 requires exploding dice and the displayed roll does not show resolved values above 6 where applicable, treat the roll as invalid.
- Report: **dice pool, TN, final dice, successes**.

Example:

`Glaze INT 13, TN 8: 2, 4, 9, 3, 1, 8, 5, 2, 15, 4, 3, 1, 5 — 3 successes.`

Each die is compared independently to the TN. A high exploded result still counts as only one success.

For Open Tests, show the completed dice and report only the highest final value. For Opposed or Success Contest tests, show both sides separately before the result. For complementary tests, show the primary and complementary rolls separately.
