## Summary

**Optical memory chips (OMCs)** are the standard small storage media of the setting, cheap to buy blank. **Optical code chips (OCCs)** are a copy-protected variant used to distribute commercial software: the program is physically etched into the chip so it can be loaded into memory once, but any further copy made from that loaded copy is unusable — this is how the setting prevents casual piracy of Matrix utilities, skillsofts, and BTL chips.

**Source vs. object code:** programs are written as human-readable source code (in in-world languages like HoloLISP or InterMod) and then compiled into object code, the actual executable form burned onto OCCs. Only someone holding the source code can modify, upgrade, or legitimately duplicate a program — object-code copies can be run but not edited or re-copied. Some black-market crackers know how to bypass this protection, but their methods aren't widely shared.

**Skillsofts** are chipped skill sets that a suitably equipped user can access to instantly perform tasks they never actually learned. Using one overrides the user's own trained ability for that skill while active — even someone who naturally has the skill falls back to the chip's rating instead of their own while it's slotted. Three subtypes exist: **knowsofts** (Knowledge/Mental skills, with **linguasofts** as a language-specific version), **datasofts** (raw reference information, with no applied skill), and **activesofts** (Active skills — combat, physical, technical, vehicle). Magic skills can't be put on activesofts.

Hardware requirements scale with soft type: datasofts need only a chipjack, display link, or image link; knowsofts need a chipjack or knowsoft link; activesofts require a full skillwire system. Chips can be downloaded permanently into headware memory (freeing the physical chip) or left slotted if memory space is unavailable. Skillsofts don't grant their associated dice pool (e.g., no Combat Pool from a Pistols activesoft). Memory footprint is calculated via the Program Size Table, with base skills at a ×3 multiplier and specializations at ×2.

A **skillsoft jukebox** is a multi-port chip reader wired to a datajack/chipjack, letting a user switch quickly between several slotted skillsofts — useful in combat. **Autonav map chips** provide detailed routing data letting Rating 2+ autonav-equipped vehicles self-drive mapped urban routes, excluding rough terrain.

**BTL (Better-Than-Life) chips** are bootleg simsense recordings with safety limiters stripped out, overloading pleasure centers with amplified sensation. They come as **Dreamdeck chips** (need a modified simsense deck) or **Direct Input Chips** (self-contained, slot directly into a jack), both normally single-use/self-destructing unless modified. Variants exist that skip the RAS override (letting users move around while chipped), loop a single intense emotion, or even overwrite personality (the "personafix" type, sometimes modeled on a real or historical figure). BTLs are highly addictive; heavy use carries serious risks — catatonia, dissociative symptoms, amnesia, flashbacks, mania, sensory crossover, and death, often from neglect or accidents while intoxicated rather than the chip itself.
