# ID Edges & Flaws — Quick Reference
No point values. ID either has it or doesn't. **Keep hidden from players** — the forger usually doesn't know either.

**Generating:** Roll 1D6 on ID purchase/creation. 1 = one random Flaw. 6 = one random Edge.
**Buying:** –20% cost per Flaw taken, +20% cost per Edge. Max 3 either way. Tell the player they're getting shoddy work; keep the specific Flaw secret.

## Edges
| Edge | Effect |
|---|---|
| Aging Well | +1 rating every (rating) months |
| Home Turf | Rating x1.5 (round up) in one GM-chosen locale/system |
| Positive Confusion | +2 TN to any test tracking the character via this ID |
| Teflon Identity | Negative records don't surface. Roleplaying tool, not immunity |
| Upstanding Citizen | –1 TN on Social tests with the checker, while the act holds |
| Watertight | –1 TN in the Opposed Test vs. ID scanner |

## Flaws
| Flaw | Effect |
|---|---|
| Dead Man's Shoes | SIN belonged to a dead person; their loose ends surface |
| Deterioration | –1 rating every (rating) months |
| Evil Twin | Someone else's bad records land on the character |
| Expiration Date | Dies/exposed at rating x 1D6 months. Reversible at GM discretion |
| Limitation | Half rating (round down) in one GM-chosen locale/system; Rating 1 auto-fails |
| Major Goof | Automated readers fine; metahuman spots it on Intelligence (4) Test |
