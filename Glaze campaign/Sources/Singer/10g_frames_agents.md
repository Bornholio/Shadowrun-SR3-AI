## Frame & Agent Special Notes
**On the Fly Command Set** SR3 Group of programs [Skill: Computer(Programming)/2] that run in order when given a command or condition, users Null Operation roll limits the maximun command set tally that can complete.
**Command Set** SR3 Group of programs that run in order when given a command or condition, users Null Operation roll limits the maximun command set tally that can complete.
**Dumb Frame:** SR3 frame with a fixed task profile and limited onboard logic. Users Initiative and Reaction. Only on same host as user.
**Smart Frame:** SR3 frame with more adaptive task logic; still a program construct, not a character. May be left on a host or change hosts.
**Agent:** Semi-autonomous Matrix program construct. Use as Matrix utility/loadout reference, not as independent plot agency unless the GM explicitly activates it.
