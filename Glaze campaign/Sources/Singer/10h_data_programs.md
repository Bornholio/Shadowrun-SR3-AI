# Data Files - Program Library

---

## General Rules

Programs are all available as source code, normal ops code.
Source Code: available to be modified, updated and upgraded. May be copied without limit.
Ops Code: Rendered into uploadable executable, may only be single depth copied.
Each rating level of source code is saved so that any rating can be loaded into memory (Optioned or Not)
**Active memory:** 3,900mp
**Deck IO:** 800mp/turn
**Headware Memory** mp cap / mp headroom
**Headware IO:** 1,000mp/turn

## Data Storage media

Multi Slot Chip Jack holds all this data (4 ports)
- Data, Programs and Skill Chip 50Gp OMC, Read Only *see 10f_deck_program_library.md*
- Deck Programs and Source Code 50Gp OMC, Read Only
- Simsense Recording 20Gp OMC (111m Emotive, 333m Sense)
- AV Recording 20Gp OMC (7 days A&V)

## House Rules

| Rule | Detail |
|------|--------|
| Map Data Size | Assumes Orientation System has 250mp Active memory |
| DNI Interface Program Size | Does not take headware memory when loaded into DNI cyberware |
| Generic TC Program | Assumes each Generic Port has 50mp Active memory to load, allowing versions to fast switch at FA |

**Column key:** | R = effective rating | AM = active memory loaded | AR = active rating

**AM/AR notation:**
- AM > 0 / AR > 0 - loaded in active memory at that rating
- AM = 0 / AR = - -  loaded into related headware (DNI cyberware, TC ports); no headware memory cost
- AM = 0 / AR = 0 - unloaded, on chip; load at headware IO speed (1,000mp/turn)
