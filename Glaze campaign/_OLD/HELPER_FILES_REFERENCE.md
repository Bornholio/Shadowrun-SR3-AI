# Helper Files Retrieval Directory

This directory tells a project chat which compiled HF source and which exact internal section contains a subject. It is a routing layer, not a replacement for the source material.

During roleplay, use this directory and the HF sources silently. Do not mention selectors, filenames, citations, hidden information, or retrieval activity to the player unless the GM explicitly asks out of character.

## How the chat should retrieve material

1. Match the request or scene against the **Use this component for** descriptions below.
2. Choose the smallest relevant set of HF selectors.
3. Open the named `HF_SOURCE` volume. If it is a routing file, follow its link to the source volume, then go directly to the exact `## HF-### — Title` heading.
4. Use only the material between that section's `HF-SOURCE-BEGIN` and `HF-SOURCE-END` markers unless another listed component is also needed.
5. If two components overlap or disagree, keep them distinct and surface the conflict to the GM out of character. Do not silently blend them.
6. Return a natural, player-facing answer without exposing this routing process.

## Instructions for numbering and sorting newly ingested files

1. Read the new file and select the best existing hundred-block category from the volume routing table.
2. Review that category's component table and assign an unused three-digit selector. Keep closely related material adjacent when practical, but never renumber an existing selector.
3. Rename the original file with its selector first: `NNN_short_descriptive_name.ext`.
4. Place the renamed original in the matching `Helper Files` category folder.
5. Insert it into the matching compiled `HF_SOURCE` file in numerical order using this structure:

```md
---

## HF-NNN — Descriptive Title

<!-- HF-SOURCE-BEGIN HF-NNN -->

[complete component content]

<!-- HF-SOURCE-END HF-NNN -->
```

6. Add the component to that volume's contents table and volume manifest.
7. Add a detailed row to this directory with the selector, component name, and what it should be used for.
8. If the file is an exact duplicate, retain the existing canonical selector and record only a duplicate alias.
9. Verify that the selector appears exactly once, the compiled text matches the original, and no unrelated files changed.

Do not ingest anything from `Helper Files/_skills/`. Do not assign either future source category until the GM defines it.
