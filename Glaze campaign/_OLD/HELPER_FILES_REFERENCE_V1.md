# HF Selector Retrieval Directory

Use this directory only to choose the smallest relevant HF selector set. Retrieve the selected HF component content from the available HF material. During roleplay, do not expose selector IDs, retrieval activity, or hidden routing mechanics to the player unless the GM asks out of character.

If multiple selectors are relevant, retrieve only those needed for the current scene or question. If retrieved HF components materially conflict, keep the conflict visible to the GM rather than silently blending them.

HF-630 through HF-633 are intentionally absent from active routing because that DNA/DOA material has already been played.
