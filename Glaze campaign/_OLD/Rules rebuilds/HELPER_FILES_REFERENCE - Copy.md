# Helper Files Chat Reference

This index assigns every in-scope file in `Helper Files` a unique three-digit selector. Use a selector in chat to identify a file without typing its path.

## How to select files in chat

- One file: `Use HF-241.`
- Several files: `Load HF-101, HF-102, and HF-110.`
- A contiguous series: `Use HF-220 through HF-223.`
- A whole category: `Review the HF-400 Matrix category.`

The `HF-` prefix is the clearest form, but the leading three-digit number in each filename is the canonical ID. Selection means the exact file listed below; category requests mean all listed files in that hundred block unless the request narrows the scope.

## Numbering scheme

| Range | Category | Expansion rule |
|---:|---|---|
| HF-100–199 | Setting, language, and culture | Use open tens for new subjects; adjacent IDs for a related series. |
| HF-200–299 | NPCs, security forces, and creatures | Keep organizations and creature families together. |
| HF-300–399 | Gear, communications, vehicles, and commerce | Keep closely related device references adjacent. |
| HF-400–499 | Matrix | Keep overview/detail companion files adjacent. |
| HF-500–599 | Seattle locations and infrastructure | Use open tens for districts and adjacent IDs for district supplements. |
| HF-600–699 | Adventures and campaign plans | Give each adventure/source collection its own span. |
| HF-700–799 | Character options, adept powers, and lifestyles | Use open tens for new option families and adjacent IDs for companion references. |
| HF-800–899 | Rules, tests, and individual spells | Use open tens for new rule families and adjacent IDs for related spell references. |
| HF-900–999 | Reserved | Future category. |

When adding a file, choose an unused ID inside its category. Do not renumber existing IDs merely to make the sequence contiguous; stable chat selectors are more important than eliminating gaps.
