## Forensic Value

**Fabrication signature:** Organometallic construction method consistent across all units — same builder. Aldric confirmed he did not build these. Builder identity GM controlled.

**Encryption:** 128-bit hardware keyed — routine recovered S10. Key in Singer's possession. Components can be examined to determine manufacturing origin if appropriate contacts are engaged.

**Browse Agent targeting profile:** Agent was keyed to behavioral markers — call duration patterns, language, time-of-day habits, repeat contact signatures. Specific markers GM controlled. Agent is intact and could be reverse-engineered to identify what the operator knew about the family's habits before the network was placed.
