## Program Notes
All programs exist as source code and ops code. Source can be copied freely; ops code only one copy deep. Each rating exists as saved source. AM = active memory loaded; AR = active rating; OC = ops-code size.

Options: Targeting = -2TN attack tests; Sneak = +1 effective DF; DINAB = unattended utility runner; Cracking = knowsoft support for DINAB; Self Coder = programming-team member.
