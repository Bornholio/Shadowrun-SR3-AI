## Frame & Agent Special Notes
**Dumb Frame:** SR3 frame with a fixed task profile and limited onboard logic.
**Smart Frame:** SR3 frame with more adaptive task logic; still a program construct, not a character.
**Agent:** Semi-autonomous Matrix program construct. Use as Matrix utility/loadout reference, not as independent plot agency unless the GM explicitly activates it.

| Program | Description |
|---------|-------------|
| Program/OMC Carrier/Courier | Allows program to be transferred to customer for burning to OCC. Will not transfer to OMC. Designed to allow safe sale of programs via deck |
| Simsense Carrier/Courier | Allows wet record simsense to be transferred and played once. Full size = 7mp + payload size |
| Call Router | Drop-in call handler for on-the-fly commcall operations. Dumps calls if it detects tracing or triangulation. Can relocate within Matrix scope |
| Data Search | Allows parallel data search. Can relocate within Matrix scope as configured. |
| Software Ripper | Allows unattended cracking of programs and data to gain source code. Includes R6 Knowsoft to allow cracking programs up to rating 6 |
| Watch Dog | Agent that can map out and understand hosts and other structures, commonly detecting deckers |
| Hound Dog | Independet Data search agent |
| Blood Hound | Mobile Trace IC |
| Fox Hound | Locates wireless actors location in the real world |
| Dispatcher | Independent call router |
