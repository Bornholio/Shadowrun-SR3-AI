## Notes below the table

The table uses a single entry per item or lot. Location is recorded in the table instead of splitting the inventory into separate custody charts. Items that are part of a larger lot, such as the workbench pieces inside the shop value, are marked as included rather than given a second sale value.

Sale valuation is based on actual/normal cost. Street Index is useful for replacement pressure, scarcity, and street acquisition, but it should not inflate the base value used for fence-sale math. The fence baseline is 30% of actual value before Negotiation shifts. Cash is not fenced at a discount unless it is traceable or locked behind some separate problem.
