## Security Ratings Use

Security ratings color response time, response quality, backup availability, jurisdiction, and reporting weight. They do not imply constant surveillance, constant checks, or automatic pressure for merely existing in a rated zone.

Beat cops, venue security, emergency services, gang lookouts, and neighborhood watchers are useful background tone. They become plot complications only when player actions make them relevant.
