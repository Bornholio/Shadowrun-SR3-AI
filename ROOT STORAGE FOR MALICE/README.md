# Shadowrun

Personal repository for a Shadowrun 3rd Edition campaign archive and GM toolkit.

The repo is organized for AI-assisted campaign prep and non-combat play support. It stores the files needed to start a session, answer rules questions, maintain character continuity, track NPCs and active mysteries, and preserve session logs.

Combat control is outside chat scope. Chats may support focused rules lookup, prep, audits, stat reference, and post-session notes, but should not run combats, manage initiative, choose tactics, stage attacks, or apply live combat damage.

## Layout

| Area | Purpose |
|---|---|
| Root `00-09` files | Session setup, chat control, current header, GM notes, adventure history, contacts |
| `RULES/` | General rules references and on-demand SR3 mechanical skill files |
| `NPC/` | Contacts, opposition, Lone Star, critters, spirits, dragons, and threat-tier stat blocks |
| `INTEL/` | Seattle geography, transit, security ratings, active mystery files, loot, and adventure plans |
| `CHARACTERS/` | Player character sheets and group support files |
| `SESSION LOGS/` | Completed session summaries and next-session headers |

## Session Use

For live campaign work, start with:

1. `01_chat_control.md`
2. `01a_skill_triggers.md`
3. `01b_output_formats.md`
4. `02_sr3_game_rules.md`
5. `03_session_header.md`

Then load only the character, rules, NPC, intel, or session-log files needed for the current scene.

`00_README.md` is the detailed operational index for the campaign.
